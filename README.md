## // What is OPEN//77?

OPEN//77 is a multiplayer platform for **Cyberpunk 2077**, built around community-hosted dedicated servers.

The goal is simple: give players and creators the tools to turn Night City into their own multiplayer experience.

Build roleplay servers, freeroam worlds, racing, PvP, custom gamemodes or something completely different.

> **The city was built for one. Open it to everyone.**

---

## // Build your own world

OPEN//77 isn't built around one official server.

Server owners run their own dedicated servers with their own:

- gameplay and rules
- resources and scripts
- maps and custom assets
- interfaces
- moderation
- communities

### For developers

Resources are built using **Lua 5.4** across client and server runtimes.

```lua
RegisterCommand("hello", function(source)
    print("Welcome to Night City.")
end)
```

Developers can build gameplay using OPEN//77 APIs for systems such as:

`Players` · `Vehicles` · `NPCs` · `Weapons` · `World` · `Animations` · `Networking` · `Audio` · `UI`

Resources can also ship **HTML / CSS / JavaScript WebUIs** for custom HUDs, menus and applications.

→ [Read the documentation](https://open2077.net/docs)

## // Community ecosystem

OPEN//77 is designed as a platform rather than a closed multiplayer experience.

Community creators can build and share:

- scripts
- gamemodes
- frameworks
- interfaces
- maps
- developer tools
- server resources

Explore community creations in the [OPEN//77 Workshop](https://open2077.net/workshop).
